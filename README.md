# Git & GitHub, visually

A single-page, interactive site that teaches core Git concepts by letting you operate them instead of just reading about them.

**Live:** https://junjing02.github.io/learn_git/

## What's on the page

- **The four Git areas** — move a file through working directory → staging → local repo → remote using buttons like `git add`, `commit`, `push`, `pull`, `reset`, `fetch`. Only valid moves are enabled, so it teaches the mental model as you go.
- **The full picture** — every command from above, plus a few more, shown at once as a map instead of one step at a time. Hover or click each one to see what it does, or run it right there.
- **Branching & merging** — grow a real commit graph by clicking buttons or typing actual git commands into a simulated terminal. Try the same scenario as a merge and as a rebase to see how the resulting history differs. Includes undo and notes on merge conflicts and history rewriting.
- **GitHub workflow stepper** — the 8 stages from fork/clone to merge & cleanup, each with a plain-English explanation and the exact commands.
- **Command reference** — a filterable, copyable table of common Git commands and what they do.
